# GitHub & Render Deployment Guide

## Overview
This guide walks you through deploying your AngelFerno bot and website to keep them online 24/7.

---

## Part 1: Prepare Your Repository

### Step 1.1: Create a GitHub Account
- Go to [github.com](https://github.com)
- Sign up or log in
- Create a new repository named `angelinferno-bot`

### Step 1.2: Initialize Git Locally
Open PowerShell in your project directory and run:

```powershell
# Navigate to your project
cd C:\Users\MUKASA\Desktop\nova\AngelInferno

# Initialize git
git init

# Add all files
git add .

# Create initial commit
git commit -m "Initial commit: AngelFerno bot and website"

# Add remote repository
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/angelinferno-bot.git

# Push to GitHub
git push -u origin main
```

**Note**: Replace `YOUR_USERNAME` with your actual GitHub username.

### Step 1.3: Files to Commit
Your GitHub repo should include:
- ✅ `fernotest.py` - Your bot file
- ✅ `requirements.txt` - Python dependencies
- ✅ `Procfile` - Render deployment config
- ✅ `render.yaml` - Render service configuration
- ✅ `.env.template` - Environment variables template (NOT real .env with secrets!)
- ✅ `Web/angelferno_merged.html` - Your website
- ✅ `.gitignore` - To exclude sensitive files

**DO NOT commit** sensitive files:
- `.env` (your real credentials)
- `wallets.db` (database with real data)
- `*.txt` (wallet files in `/wallets/` folder)

## Part 2: Deploy to Render

### Step 2.1: Create Render Account
1. Go to [render.com](https://render.com)
2. Click "Sign Up"
3. Connect your GitHub account
4. Authorize Render to access your repositories

### Step 2.2: Create New Service
1. Click **"New +"** → **"Web Service"**
2. Select your `angelinferno-bot` repository
3. Fill in the form:

| Field | Value |
|-------|-------|
| **Name** | `angelinferno-bot` |
| **Environment** | `Python 3` |
| **Region** | `Oregon` (US) or closest to you |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `python fernotest.py` |
| **Plan** | Free (750 hours/month) |

### Step 2.3: Add Environment Variables
After creating the service, go to **Settings** → **Environment** and add:

```
TELEGRAM_BOT_TOKEN=your_actual_token_here
TELEGRAM_MODE=webhook
TELEGRAM_WEBHOOK_URL=https://angelinferno-bot.onrender.com/webhook
OCRS_SECRET_KEY=your_secret_key_here
```

**Where to get these values:**
- `TELEGRAM_BOT_TOKEN`: Your bot token from @BotFather
- `TELEGRAM_WEBHOOK_URL`: Will be generated by Render (format: `https://{service-name}.onrender.com`)
- `OCRS_SECRET_KEY`: Generate a random secure string (min 32 characters)

### Step 2.4: Deploy
Click **"Create Web Service"** → Wait 3-5 minutes for deployment

✅ Your bot is now live at: `https://angelinferno-bot.onrender.com`

## Part 3: Connect Telegram Webhook

### Step 3.1: Verify Bot Webhook URL
Run this in PowerShell:

```powershell
$botToken = "your_token_here"
$webhookUrl = "https://angelinferno-bot.onrender.com/webhook"

$response = Invoke-WebRequest `
  -Uri "https://api.telegram.org/bot$botToken/setWebhook" `
  -Method POST `
  -Body @{
    url = $webhookUrl
    drop_pending_updates = "true"
  } `
  -ContentType "application/x-www-form-urlencoded"

$response.Content | ConvertFrom-Json | ConvertTo-Json
```

Expected response:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

### Step 3.2: Verify Webhook is Active
```powershell
$botToken = "your_token_here"

$response = Invoke-WebRequest `
  -Uri "https://api.telegram.org/bot$botToken/getWebhookInfo" `
  -Method GET

$response.Content | ConvertFrom-Json | ConvertTo-Json
```

Should show:
```json
{
  "url": "https://angelinferno-bot.onrender.com/webhook",
  "has_custom_certificate": false,
  "pending_update_count": 0,
  "last_error_date": null
}
```

## Part 5: Update Your Website

Update your `angelferno_merged.html` to point to your Render bot:

**Find this line:**
```javascript
PRODUCTION_API_URL: 'https://angelferno-bot.onrender.com',
```

**Make sure it matches:**
```javascript
const API_CONFIG = {
    PRODUCTION_API_URL: 'https://angelinferno-bot.onrender.com',
    LOCAL_API_URL: 'http://localhost:8080',
    getAPIBase: function() {
        const isLocal = window.location.hostname === 'localhost' || 
                       window.location.hostname === '127.0.0.1';
        return isLocal ? this.LOCAL_API_URL : this.PRODUCTION_API_URL;
    }
};
```

## Part 6: Ongoing Maintenance

### Auto-Deploy from GitHub
Render watches your GitHub repo. When you push changes:
```powershell
git add .
git commit -m "Update bot features"
git push origin main
```

Render automatically deploys within 30 seconds.

### Monitor Logs
- Go to Render dashboard
- Click your service
- View **Logs** tab for real-time output

### Keep Bot Awake (Optional)
Free tier spins down after 15 minutes of inactivity. To keep it warm, Render sends health checks automatically when webhook mode is enabled.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Bot goes offline after 15 mins | Webhook mode activates health checks automatically |
| Build fails | Check `requirements.txt` has all imports |
| Webhook returns 502 | Wait 2 minutes, Render may be restarting |
| Website can't reach bot | Verify `PRODUCTION_API_URL` in HTML matches Render URL |
