# 🚀 AngelFerno Panel - Quick Start (30 seconds)

## Step 1: Run the Bot
```
python fernotest.py
```
Wait for: `Running on http://0.0.0.0:8080`

## Step 2: Find Your IP
### Windows Command Prompt:
```
ipconfig
```
Look for **IPv4 Address** (e.g., `192.168.1.100`)

## Step 3: Open Browser
On **any device on your network**, go to:
```
http://[YOUR-IP]:8080
```
Example: `http://192.168.1.100:8080`

## Step 4: Login
Use your credentials → Done! ✅

---

## Alternative Ways to Access

| Method | URL |
|--------|-----|
| Same computer | `http://localhost:8080` |
| Using computer name | `http://COMPUTER-NAME:8080` |
| Using IP | `http://192.168.x.x:8080` |

---

## ⚠️ Connection Error? 

1. **Server running?** → Check step 1
2. **Same network?** → Both devices on same WiFi
3. **Firewall?** → Allow port 8080 in Windows Firewall
4. **Correct IP?** → Use `ipconfig` to verify
